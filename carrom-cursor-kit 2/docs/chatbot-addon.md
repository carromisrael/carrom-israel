# Optional chat channel — planning addendum
Discussed after the original business spec; not included in current implementation.

A quiet lower-right launcher can open chat inside the site, with clear handoff to WhatsApp. Do not auto-open on entry or compete with a second floating control in the same corner. First uses: explain Carrom, assist model selection, direct to purchase or a person. Anonymous general questions are allowed; order-specific information requires identity verification.

Use the same catalog, order and CRM services. Start with approved knowledge and human handoff, later add narrow server-authorized tools. Never invent prices, stock or delivery promises. Distinguish chat opened, message received, qualified inquiry and paid order in analytics. Provide rate/cost limits, retention/consent decisions and a human fallback. Login is not required merely to open chat. Separate draft generation from confirmed message delivery. CRM connection, agent vendor and launch date remain open.
