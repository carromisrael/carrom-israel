# Carrom Israel — חבילת Cursor מעודכנת
גרסה 2 · 24.09.2026

## מתחילים כאן
1. חלץ את התיקייה carrom-cursor-kit לשורש פרויקט Next.js הקיים. אם קיימת חבילה ישנה, שמור אותה בצד והשתמש בגרסה זו.
2. פתח motion-reference.html בדפדפן: תצוגת הירו חיה עם תנועה ושלושה שילובי צבע לכפתור ולכותרת. זו תצוגה מקומית, לא אתר שפורסם.
3. פתח Agent ב־Cursor וצרף design.md ואת references/hero-single-charcoal.png.
4. הדבק את כל CURSOR_PROMPT.md. הוא מכוון למימוש ההאדר וההירו בפרויקט הקיים.
5. בדוק מחשב ומובייל לפני שממשיכים לסקשנים האחרים.

## מה נעוץ ומה פתוח
בסיס המימוש הוא לוח העץ היחיד, רקע פחם וניווט ממורכז. המניפה מצורפת כרפרנס חלופי. צבע הכפתור והכותרת עדיין להשוואה: זהב כמו בסקיצה, כפתור כחול עמום וכותרת זהב, או שניהם כחולים. הרקע נשאר פחם. אפשרות הצבעים אינה חלק מהאתר הציבורי.

## תכולה
- design.md — עיצוב, טקסטים, מרווחים, מובייל, צבעים ותנועה.
- CURSOR_PROMPT.md — פרומפט למימוש.
- starter/ — רכיב TSX, CSS Module וטוקנים מותאמים לגרסה הנוכחית.
- motion-reference.html — תצוגה חיה ללא התקנת חבילות; כולל תפריט נייד ומעבר בין צבעי הדגשה.
- references/ — שתי הסקיצות האחרונות באפור־פחם.
- assets/ — תמונת לוח נפרדת בשקיפות, לוגו מקורי כרפרנס ותצלומי שלושת המוצרים.
- docs/carrom-sales-platform-spec.md — האפיון העסקי המלא שנכתב, ללא שינוי.
- docs/chatbot-addon.md — התוספת על צ׳אט אופציונלי.
- ASSETS.md — מקור כל תמונה ומגבלות שימוש.
- IMPLEMENTATION_CHECKLIST.md — סדר עבודה ובדיקות.
- VALIDATION.md — מה נבדק בחבילה ומה נותר לאינטגרציה.

## שילוב
העתק assets/champion-hero.webp לתיקיית public המתאימה. טען starter/tokens.css פעם אחת בסגנונות הגלובליים. הרכיב כולל header: אם יש האדר קיים, שלב אותו ולא שניים.

```tsx
<CarromHero
  logoSrc="/brand/carrom-logo.svg"
  boardSrc="/images/champion-hero.webp"
  accent="gold"
  modelsHref="#models"
  aboutHref="#about"
  eventsHref="#events"
/>
```

הנתיבים והעוגנים הם דוגמה; יש לוודא שהם קיימים בפרויקט. accent יכול להיות gold, mixed או blue.

## חשוב לפני פרסום
P1 נשאר פרטי. תמונת הלוח השקופה נוצרה ב־AI ומאפשרת להתקדם ב־UI, אך אינה צילום מדויק של המלאי. הלוגו המקורי המצורף הוא JPG עם רקע לבן; יש להשתמש בלוגו שקוף אותנטי מהפרויקט. בתצוגה המקומית יש טקסט זמני מסומן במקום לוגו סופי.

אין צורך במפתחות API כדי לפתוח את התצוגה. החבילה אינה כוללת חיבור סליקה או פרטי לקוחות. קוד ההתחלה דורש התאמה לריפו שלכם; אין כאן טענה שהריפו נבנה או נבדק.
